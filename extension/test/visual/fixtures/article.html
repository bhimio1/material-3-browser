Setting up Hyprland on Arch, the comfortable way

Most guides throw a wall of config at you. This one starts with the official wiki, then adds only what you need: a bar, a launcher and a sensible keybind layout.

Start small. You can always add more later.
sudo pacman -S hyprland kitty waybar fuzzel
hyprctl reload
Tip: keep your config in a git repository so you can roll back.
